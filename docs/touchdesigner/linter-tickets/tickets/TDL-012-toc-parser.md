## Problem Statement

The .toc file is the manifest that lists all files in a .toe.dir. Validation should ensure: (1) every file in .toc exists on disk, (2) every relevant file on disk is in .toc. Mismatches indicate corruption or incomplete expansion.

## Acceptance Criteria

- [ ] Parser reads .toc file and extracts file list
- [ ] Validator checks all .toc entries exist on disk
- [ ] Validator checks all .n/.parm files on disk are in .toc
- [ ] Special entries handled (.build, .start, .grps, .root, .application)
- [ ] Clear error messages for missing/extra files
- [ ] Works in pre-collapse mode (partial .toc OK)

## Research Pointers

### .toc File Structure

```
.build
.start
.grps
.root
.parm
project1.n
project1.parm
project1.panel
project1/geo1.n
project1/geo1.parm
...
.application
```

Observations:
- Line-delimited file paths
- Paths are relative to .toe.dir root
- Special files start with `.`
- Hierarchy indicated by `/`

### Special Entries

| Entry | Purpose |
|-------|---------|
| .build | Build metadata |
| .start | Startup configuration |
| .grps | Group definitions |
| .root | Root operator reference |
| .parm | Root parameters |
| .application | Application settings |

Some of these are generated by toecollapse and may not exist in manually created .toe.dir.

### Pre-collapse Mode (CM-001)

When validating a manually created .toe.dir before collapse:
- .application may not exist
- .panel files may not exist
- .toc may be incomplete or missing

The validator should have a `--pre-collapse` flag that relaxes these checks.

### Validation Logic

```
1. Read .toc, parse into set of paths
2. Walk filesystem, collect all files into set
3. toc_only = toc_set - fs_set  (in manifest but missing)
4. fs_only = fs_set - toc_set   (on disk but not in manifest)
5. Report both as potential issues
```

### Edge Cases

- Empty .toc file
- .toc with paths that don't exist
- Files on disk not in .toc
- Paths with special characters
- Case sensitivity (matters on some filesystems)

## Why This Matters

- Missing files cause toecollapse to fail or produce corrupt .toe
- Extra files may be orphaned content
- Early detection saves debugging time

## Definition of Done

All acceptance criteria checked. Parser handles sample corpus .toc files correctly.
