# Max Externals Tests

This directory contains tests for the Max/MSP externals and GenExpr shader files.

## Test Files

### test_genexpr_syntax.py

Comprehensive validation suite for all `.genjit` shader files in the `code/` directory.

**What it validates:**

1. **File Structure**
   - Files are readable and non-empty
   - Documentation headers present
   - Proper file format (GenExpr or GLSL-wrapped)

2. **Parameter Declarations**
   - GenExpr: `Param name(default);` format
   - GLSL: `<param name="..." type="..." default="..." />` XML format
   - All parameters properly formatted with semicolons

3. **Output Assignments**
   - GenExpr shaders: `out = ...` or `out1[n] = ...`
   - GLSL shaders: `gl_FragColor = ...`

4. **Syntax Validation**
   - Matching braces in functions
   - Proper function definitions
   - No obvious undefined variables (basic check)

5. **PCG RNG Constants** (critical for deterministic randomness)
   - PCG_MULT = 747796405
   - PCG_INC = 2891336453
   - PCG_FACTOR = 277803737
   - COORD_PRIME_X = 374761393
   - COORD_PRIME_Y = 668265263

6. **GLSL Shader Structure** (for wrapped shaders)
   - `<jit.gl.pix>` wrapper present
   - `<description>` tag
   - `<language name="glsl">` declaration
   - `<program type="fragment">` with `void main()`
   - `#version` directive in GLSL code

## Running Tests

### From the project root

```bash
# Activate virtual environment
source .venv/bin/activate

# Run all GenExpr syntax tests
pytest max-externals/tests/test_genexpr_syntax.py -v

# Run specific test class
pytest max-externals/tests/test_genexpr_syntax.py::TestGenExprSyntax -v

# Run tests for a specific shader
pytest max-externals/tests/test_genexpr_syntax.py -k "sr.noise" -v

# Run only PCG constant validation
pytest max-externals/tests/test_genexpr_syntax.py::TestGenExprSyntax::test_pcg_constants_correct -v
```

### From the max-externals directory

```bash
cd max-externals
source ../.venv/bin/activate
pytest tests/test_genexpr_syntax.py -v
```

## Adding New Shaders

When adding a new `.genjit` file to the `code/` directory:

1. **Required elements for GenExpr shaders:**
   - Documentation header comment (`/**` or `/*`)
   - At least one `Param name(default);` declaration
   - Output assignment: `out = ...`
   - Matching braces for all functions
   - If using PCG RNG, include all constants with correct values

2. **Required elements for GLSL shaders:**
   - `<jit.gl.pix>` wrapper tags
   - `<description>` tag
   - `<param>` XML tags for parameters
   - `<language name="glsl">` with version
   - `<program type="fragment">` with CDATA
   - `void main()` function
   - `#version` directive
   - Output assignment: `gl_FragColor = ...`

3. **Run the tests** to verify your shader passes all validation:
   ```bash
   pytest max-externals/tests/test_genexpr_syntax.py -v
   ```

## PCG Constants Reference

These constants must match exactly across all implementations (Python, Taichi, Max GenExpr, GLSL):

```python
PCG_CONSTANTS = {
    "PCG_MULT": 747796405,      # PCG state multiplier
    "PCG_INC": 2891336453,       # PCG increment
    "PCG_FACTOR": 277803737,     # PCG output permutation
    "COORD_PRIME_X": 374761393,  # Prime for X coordinate hashing
    "COORD_PRIME_Y": 668265263,  # Prime for Y coordinate hashing
}
```

These values ensure that random noise patterns generated in Max match those generated by Python/Taichi for testing and validation.

## Troubleshooting

### Test fails: "File X has no Param declarations"
- Add at least one `Param name(default);` line to your shader
- For GLSL shaders, add `<param name="..." type="..." default="..." />`

### Test fails: "File X has no output assignment"
- GenExpr: Add `out = ...;` somewhere in your shader
- GLSL: Add `gl_FragColor = ...;` in your main() function

### Test fails: "PCG_MULT = X, expected Y"
- Update the constant value to match the reference
- These values must be identical across all implementations

### Test fails: "Mismatched braces"
- Check that every `{` has a matching `}`
- Common issue: missing closing brace in function definitions
